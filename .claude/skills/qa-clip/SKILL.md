# /qa-clip — ทีม QA จับผิดคลิป

1. **เตรียมข้อมูลร่วม (หัวหน้าทำเอง ครั้งเดียว ไม่เปลือง token ทีม)**
   ```
   node engine/qa/probe.mjs <id>
   python -m engine.qa.analyze <id>
   node engine/render/contact.mjs <id> --every 2
   ```
2. **เรียก 3 คนพร้อมกัน** (Agent tool, run_in_background) แต่ละคนเขียน `jobs/<id>/qa/<ชื่อ>.md`
   - `qa-visual` สรีระ · ภาพบิดเบี้ยว/ขาดหาย · ตัวละครสลับตัว
   - `qa-motion` ท่าทาง · การเคลื่อนไหวตัวละคร ฉาก สิ่งของ สิ่งก่อสร้าง
   - `qa-av` เสียงเอฟเฟกต์ · ลิปซิงก์ · ขยับตัวตรงเสียง
3. **รวมผล → `jobs/<id>/qa/report.md`** (หัวหน้าทำ)
   - รวม 3 ตาราง + auto_findings · ตัดรายการซ้ำ (เวลาซ้อนกัน + อาการเดียวกัน = รายการเดียว ให้คนที่มีหลักฐานชัดกว่า)
   - เรียงตามเวลา · ส่วนหัวสรุป: จำนวน สูง/กลาง/ต่ำ และช่วงเวลาที่มีปัญหามากที่สุด
   - แยกส่วน "ส่งให้": animator / film-director / sound / editor — แต่ละส่วนเป็นรายการที่ต้องแก้ พร้อมเวลาและหลักฐาน
4. **ส่งงานแก้**: ส่งเฉพาะรายการ สูง+กลาง ให้แต่ละตำแหน่ง (Agent tool พร้อม path ของ report.md ส่วนของตัวเอง) — รายการต่ำ ถามผู้ใช้ก่อน
   - แก้ภาพ → `node engine/qa/probe.mjs` + `analyze` ซ้ำเฉพาะเพื่อยืนยัน · ถ้าแก้เสียงอย่างเดียวใช้ remux
   - วนตรวจซ้ำได้สูงสุด 2 รอบ ยังไม่ผ่าน → รายงานผู้ใช้พร้อมรายการค้าง
5. **อัปเดตออฟฟิศ**: role = qa-visual ระหว่างตรวจ (ทีม QA นั่งห้องตัดต่อ) · note = "QA พบ N จุด ส่งแก้แล้ว"
6. **รายงานผู้ใช้**: ตารางเวลา → อาการ → ใครแก้ → สถานะ (แก้แล้ว/ค้าง)
