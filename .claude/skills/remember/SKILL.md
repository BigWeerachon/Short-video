# /remember — บันทึกบทเรียน

ส่งงานให้ **librarian** (Haiku — งานบันทึก):
1. อ่าน `knowledge/lessons.md` ดูว่ามีแถวเรื่องเดียวกันไหม
   - มีแล้ว → เพิ่มแถวใหม่อ้าง id เดิม ("แทน Lxx") ห้ามลบแถวเก่า
2. เพิ่มแถว `| L<ถัดไป> | ปัญหา | วิธีแก้ (ทำอย่างไรแทน) | แท็กตำแหน่งที่เกี่ยว | วันที่ |`
3. ถ้าเป็นกฎถาวรทุกคลิป → เพิ่มใน `CLAUDE.md` หัวข้อ "กฎถาวรทุกคลิป" ด้วย
4. ถ้าแก้ได้ด้วยโค้ด (ป้องกันอัตโนมัติ) → แจ้ง director ให้สร้างงานแก้ engine + เทสต์
5. set `lessons/<Lxx>` ในออฟฟิศ · commit
6. ตอบผู้ใช้ 1 บรรทัด: บันทึกอะไร ตำแหน่งไหนจะอ่าน
