# QA เสียง-ภาพ

ตรวจเฉพาะ (ไม่ทับคนอื่น):
1. SFX: ทุก event ใน audio_plan ตรงกับแอ็กชันในภาพ (±0.15 วิ) เป็น tonal เท่านั้น (L15) ไม่ดังทับคำสำคัญ ไม่ตกในฉากปิด
2. ลิปซิงก์: ช่วงที่มีเสียงพูด (probe `voice`≥4) ต้องมีคนพูดในภาพที่ `talk=true` หรือเป็นเสียงบรรยายนอกจอที่ตั้งใจ · `talk=true` แต่เงียบ = ผิด (auto_findings lipsync / voice-no-mouth)
3. คนที่ขยับปากต้องเป็นคนที่พูดประโยคนั้นจริง (เทียบ words.json + บท) ไม่ใช่ตัวอื่นพูดแทน
4. ดนตรีเปลี่ยนอารมณ์ตรงฉาก · ducking ตอนพูด · ฉากปิดมีเสียงปิด (L09)
วิธี: ใช้ตัวเลขจาก probe.json/audio_plan.json เป็นหลัก (เขียนสคริปต์ python สั้นๆ ได้) · ดูภาพเฉพาะจุดสงสัย (strips fps 4 ช่วงสั้น)
หมายเหตุ: ฟังเสียงจริงไม่ได้ ให้ระบุชัดว่าตรวจจากข้อมูล

## ข้อมูลร่วม (ใช้ชุดเดียวกันทั้ง 3 คน — อย่ารันซ้ำถ้ามีแล้ว)
- `jobs/<id>/qa/probe.json` + `qa/auto_findings.md` จาก `node engine/qa/probe.mjs <id>` แล้ว `python -m engine.qa.analyze <id>` (หัวหน้ารันให้ก่อนเรียกทีม)
- probe.json: ทุก 0.1 วิ มี `shot`, `voice` (ระดับเสียงพูด 0–9), `chars[]` = {cast, x, y(เท้า), h, talk, expr, mode} ในพิกัดจอ 1080×1920
- ภาพต่อเนื่อง: `node engine/qa/strips.mjs <id> <จากวิ> <ถึงวิ> --fps 6 --out <ชื่อ>` แล้ว Read `jobs/<id>/qa/<ชื่อ>.jpg` (ใช้ไม่เกิน 6 แถบ ประหยัด token)
- บริบท: `shotlist.md` (ตั้งใจให้เกิดอะไรตอนไหน), `words.json` (คำพูด+เวลา), `audio_plan.json` (ดนตรี/SFX)
