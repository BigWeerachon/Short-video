# คู่มือทำคลิปเล่าเรื่อง 2D Animation โฆษณา PAAKIN (ใช้ต่อในแชทใหม่)

> สรุปจากงานคลิป "เดอะโกสต์แก๊งซ่า: ศึกผีภูกระดึง" และคลิปก่อนหน้า (burnout, ghost gang ฯลฯ)
> ใช้เป็นบรีฟตั้งต้น: แปะไฟล์นี้ + บท TXT + ไฟล์เสียง ElevenLabs ในแชทใหม่ได้เลย

---

## 1. เป้าหมายงาน
- คลิปแนวตั้ง **9:16, 1080×1920, 30fps** เล่าเรื่องสนุก/หลอน/ฮา แล้ว soft-sell **PAAKIN** ([www.paakin.com](https://www.paakin.com): เว็บไซต์โรงแรมพร้อมระบบจองตรง + ระบบจัดการโรงแรม SaaS)
- Input จากฉัน: บท `.txt` + ไฟล์เสียงพากย์ `.mp3` (ElevenLabs) + (บางครั้ง) รูปอ้างอิง
- Output: **MP4** ดาวน์โหลดได้ และ/หรือ **HTML5 Canvas Motion player** (Artifact) ที่เล่น/เลื่อน/เปิดปิดซับได้

## 2. กฎถาวร (ต้องทำทุกคลิป)
1. **ฉากปิดทุกคลิป**: ภาพ End card PAAK IN (มาสคอต + "ต้องที่ [www.paakin.com](https://www.paakin.com)") + เสียงปิด (end voice) ต่อท้ายหลังเสียงพากย์จบ (~7 วิ)
   - ใน HTML player: **รวมเสียงพากย์ + เสียงปิดเป็นไฟล์เดียว** (มือถือบล็อกการเล่นไฟล์เสียงที่สองอัตโนมัติ → เสียงหาย)
2. **ไม่มีลายน้ำโลโก้มุมขวาล่าง** (สั่งเอาออกแล้ว)
3. **ห้ามเสียงเอฟเฟกต์แนว noise**: ไม่เอาเสียงคลื่น ลมหวือ whoosh ถอนหายใจ ซู้ด — ใช้เสียงแบบ "โน้ตดนตรี/tonal" เท่านั้น
4. **ดนตรีประกอบ**: ชอบโทนสดใส น่ารัก; เปลี่ยนอารมณ์ตามฉาก; ลดเสียงเพลงอัตโนมัติขณะมีคนพูด (ducking)
5. **ความเร็วเสียง**: บางงานให้เร่ง VO ~1.1x (atempo) — ถามก่อน/ตามที่ระบุในแชท
6. **ภาพ**: 2D flat vector สีสดใส ไม่ใช่ pixel art ไม่มืดหม่น ไม่มีเส้นขอบ (หรือ Chibi 3D ถ้าขอ)
7. **โลโก้ PAAK IN ในฉาก** วางบนการ์ดขาวมุมมน จัดกึ่งกลางสวย ๆ
8. ตอบเป็น **ภาษาไทย**

## 3. ขั้นตอนการทำงาน (Workflow ที่ได้ผล)

### ขั้นที่ 1 — ตรวจเสียงกับบทให้ละเอียดก่อนทำภาพ (สำคัญที่สุด)
- **ห้ามประมาณเวลาด้วยสัดส่วนความยาวทั้งเรื่อง** → ภาพจะคลาด 1–2 วิ (ปัญหาใหญ่รอบแรก)
- วิธีที่ใช้ (ไม่มี ASR/Whisper เพราะดาวน์โหลดโมเดลไม่ได้):
  1. `ffmpeg silencedetect=n=-36dB:d=0.1` → ได้ช่วงพูด (speech chunks)
  2. แตกบทเป็น "วลี" ตามช่องว่าง/เครื่องหมาย
  3. **DP alignment**: จับคู่กลุ่มวลีกับกลุ่มช่วงพูด ให้ระยะเวลาพูดใกล้ (จำนวนตัวอักษร × อัตราพูด) ที่สุด, ยอมให้วลีคร่อมช่วงเงียบได้ (penalty ต่ำ ~1.0×ความยาวช่วงเงียบ)
  4. ได้ `words.json` = [{w, s, e}] เวลาเริ่ม/จบของทุกวลี → ทุกอย่างอ้างอิงจากนี้
- ตรวจผลด้วยตา: วลีสั้นผิดปกติ (เช่น ประโยคยาว 0.6 วิ) = จับคู่ผิด ต้องปรับ penalty
- ฟังก์ชันใช้ในโค้ด: `T(i)` เวลาเริ่มวลี, `TW(i,'คำ')` เวลาของคำย่อยในวลี (แบ่งตามตำแหน่งตัวอักษร)
- **เปลี่ยนไฟล์เสียงใหม่ = ต้อง align ใหม่ทั้งหมด**
- ทำ **envelope เสียง 30fps** (RMS → 0–9) ไว้ขยับปากแบบ deterministic (ใช้ได้ทั้ง preview และ export)

### ขั้นที่ 2 — Shot list ผูกกับคำพูด
- ทุกช็อตเริ่มที่ `T(i)` ของวลี, ตัดภาพทุก 1–5 วิ (wide / close-up / zoom / pan)
- **ทุกแอ็กชันเกิดตรงคำ**: ชื่อตัวละครเด้งตอนเอ่ยชื่อ, รอยเท้าตอน "ฉับ", มือโผล่ตอน "มือ", คว้าตอน "คว้าคอ", ไฟฉายส่องตอน "ส่อง", โลโก้ตอน "พักอิน", ภาพการกดจองแบบคลิกไม่กี่ครั้งในวลี "ไม่กี่คลิก" (ห้ามระบุจำนวนคลิกเป็นตัวเลข — L17)
- **การ์ดอธิบาย/อินโฟกราฟิกต้องค้างจนพูดอธิบายจบ** — รวมหลายวลีที่อธิบายเรื่องเดียวกันเป็นช็อตเดียว (การ์ดซ้อนเพิ่มทีละใบ) อย่าให้หายตอนตัดช็อต
- ปากขยับเฉพาะตัวที่ "กำลังพูดจริง" (ผู้เล่าในสตูดิโอ / ตัวละครตอนพูดประโยคตัวเอง)

### ขั้นที่ 3 — Character rig (2D canvas)
- หัวไข่ใหญ่, แขนขาเรียว, flat vector
- **ใช้ 2-bone IK** หาข้อศอก/เข่าจากตำแหน่งมือเป้าหมาย (ไม่ใช้มุมแบบเดา — เคยกลับด้าน แขนไขว้ผิดธรรมชาติ)
  - ข้อศอกเลือกด้าน "ออกนอกตัว" เป็นค่าเริ่มต้น; ท่ากอดอก/ถือมือถือเลือก "ลง"
  - ท่ามือขึ้นหน้า (ปิดปาก/ปิดตา/แก้ม/ถือมือถือ) → **วาดแขนหลังหัว** ไม่งั้นจมหายหลังหัว
- **แขนเสื้อสีเข้มกว่าลำตัว ~14%** (เสื้อขาวของนัทเคยกลืนกัน ดูบิดเบี้ยว)
- **หลีกเลี่ยงท่ามือแตะคาง** (มือสีผิวกลืนหน้า + แขนเสื้อพาดหน้า ดูแปลก)
- ยืน: ขาตรง (IK ทำขาโก่ง) / นั่ง: ขัดสมาธิมองหน้าตรง / นอน: ถุงนอน
- **ท่าเดิน/วิ่ง**: เป็นท่าข้าง — สะโพกชิดกลาง, เท้าก้าวหน้า-หลังสลับ, เข่างอไปหน้า, เท้าที่ก้าวยกพ้นพื้น, ขาหลังสีเข้มกว่า; แขนห้อยข้างลำตัวแกว่งสวนขา (ห้ามขาแกว่งออกข้างแบบกรรไกร, ห้ามมือมาประสานหน้าท้อง)
- ไม่ดุ๊กดิ๊กตลอดเวลา — แค่หายใจเบา ๆ; ท่าทางเปลี่ยนตามคำพูด
- สีหน้า: happy, smug, scared, shock, sad, cry (น้ำตา), laugh, pale (หน้าซีด), angry, sleep; กระพริบตาเป็นระยะ
- **อุปกรณ์ที่ชี้ไปที่เป้า (ไฟฉาย)**: ให้แขนเล็งไปที่เป้าหมายในฉาก, ตัวไฟฉายหมุนตามทิศเล็ง, ลำแสงออกจาก "หัวไฟฉาย" ไปทางเดียวกัน — ห้ามวาดลำแสงแยกในฉาก
- **สิ่งที่ต้องอ่านออกทันที (มือดำ)**: วาดเป็นแขน+ฝ่ามือ+4 นิ้ว+นิ้วโป้ง, มีขอบเรืองแสงตัดกับพื้นหลัง, มีรอยผ้าฉีกก่อนโผล่, นิ้วกางแล้วกำตอนคว้า, ไม่บังหน้าตัวละคร
- ตัวละครเยอะในกรอบ (รูปถ่าย/การ์ด) → ย่อและกำหนดตำแหน่งให้ **อยู่ในกรอบครบทุกตัว**

### ขั้นที่ 4 — ตัวอักษร / ซับ
- ซับ **46px บรรทัดเดียว**, กล่องพื้นเข้มโปร่งด้านหลัง, คำสำคัญสีเหลือง
- ตัดคำด้วย `Intl.Segmenter('th', {granularity:'word'})` ไม่ตัดกลางคำ
- ทุกข้อความใช้ฟังก์ชันย่อขนาดอัตโนมัติไม่ให้เกินขอบ (max width ~940px)
- **ฝังฟอนต์ Kanit (woff2 thai + latin) ในโปรเจกต์** + `document.fonts.load('700 40px Kanit','กขค abc')` ก่อนวาด
- อย่าใส่ข้อความที่ไม่ได้สั่ง (เช่น "EP.13" บนโต๊ะ — ถูกสั่งเอาออก)

### ขั้นที่ 5 — ฉาก / องค์ประกอบ
- ผู้เล่าในสตูดิโอ: ยืน **หลังโต๊ะ** (วาดโต๊ะทับขา) ไม่ใช่ยืนบนโต๊ะ
- กล้อง zoom/pan ต้อง clamp ไม่ให้เห็นขอบดำ; ช็อตสั่นกล้องให้ zoom ≥1.03
- เลี่ยงซ้อนทับ: ถุงนอน/ตัวละคร/ตัวละครที่ถูกลากต้องมีทางว่าง
- เนื้อหาหลักอยู่เหนือโซนซับ (y < ~1650)

### ขั้นที่ 6 — เสียง (ดนตรี + SFX) ด้วย numpy
- ดนตรีแบ่งช่วงตามอารมณ์ (ตัวอย่างคลิปผี): spooky น่ารัก → สดใส → พระอาทิตย์ตก → หลอน (drone+ระฆัง+หัวใจเต้น) → วิทยาศาสตร์กวน ๆ (pizzicato) → horror ตึงเครียด → chase 150bpm → เศร้า → สดใส/อบอุ่น → outro
- SFX tonal ตรงคำ: step, boom, sting (คอร์ดไม่ลงตัว), theremin (ผี), boing, squeal, heartbeat, wah (ร้องไห้ตลก), click (ไฟฉาย), fanfare, chime/sparkle (การ์ด/โลโก้), bell (นาฬิกา)
- Mix: voice 1.0, music ~0.42 × ducking (0.45 ตอนพูด), sfx ~0.42; normalize peak 0.97
- ใน HTML player ใช้ไฟล์เสียงที่ mix แล้ว และปิด WebAudio SFX สด (กันซ้ำ)

### ขั้นที่ 7 — ตรวจก่อนส่ง (ทำตัวเป็นนักวิจารณ์หนัง + ผู้กำกับ)
- เรนเดอร์เฟรมนิ่งหลายจุดด้วย headless Chrome ผ่าน `?t=วินาที` + `window.renderAt(t)` → ทำ contact sheet ดู
- เช็กลิสต์: สรีระ/แขนขา, การเดินเป็นธรรมชาติ, สีหน้า-อารมณ์ตรงบท, ท่าทางตรงคำ, องค์ประกอบ/การซ้อนทับ, แสงสี, ทิศอุปกรณ์ (ไฟฉาย), ข้อความครบ อ่านง่าย ไม่ล้นขอบ, ตัวละครครบในกรอบ, ฉากปิด+เสียงปิด, ไม่มีลายน้ำ
- บอกตรง ๆ ว่าเช็กจากภาพนิ่ง ยังไม่ได้ฟังเสียงจริง

### ขั้นที่ 8 — Export MP4
- วนเฟรม 30fps → `canvas.toDataURL('image/jpeg',.92)` ทีละ 10 เฟรม → pipe เข้า `ffmpeg -f image2pipe` + ไฟล์เสียง mix → libx264 crf 20, yuv420p, faststart
- ~7,000 เฟรม (3:54) ใช้เวลา ~8–10 นาที
- ถ้าแก้แค่เสียง: remux `-c:v copy` กับเสียงใหม่ ไม่ต้องเรนเดอร์ภาพใหม่

## 5. ตัวละครชุด "แก๊งซ่า" (ใช้ซ้ำได้)
| ตัว | ลักษณะ |
|---|---|
| ผม (ผู้เล่า) | เสื้อม่วง, ผมสั้นดำ |
| ไอ้เบิ้ม | ร่างยักษ์ (1.28×, ตัวกว้าง), เสื้อเขียว, ผมเกรียน, ใจปลาซิว |
| ยัยมีน | เสื้อชมพู, ผมยาวน้ำตาล, ตั้งสติเก่ง, จองโรงแรมผ่านพักอิน |
| ฝาแฝด (พี่/น้อง) | เสื้อส้ม ผมตั้ง, แฝดน้องใส่หมวกฟ้า |
| นัท | เสื้อเชิ้ตขาว+เนกไทฟ้า, แว่นดำ, สายวิทย์ |

## 7. ข้อจำกัดของสภาพแวดล้อม
- ไม่มี Whisper/ASR → alignment ระดับวลี คลาดได้ ~0.3 วิ กลางประโยคยาว
- สร้างภาพ/วิดีโอ AI (Chibi 3D แบบ Pixar) เองไม่ได้ — ทำได้แค่ "pseudo-3D" ด้วยแสงเงา gradient บน canvas
- ถ้าต้องการ 3D จริง: ใช้ AI image/video ภายนอก → ให้ Claude เขียน character sheet + shot list + prompt ทุกช็อต แล้วส่งคลิปกลับมาประกอบ
