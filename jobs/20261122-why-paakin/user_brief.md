# บรีฟผู้ใช้ (ต้นฉบับย่อ) — ทำไมเจ้าของโรงแรมยุคใหม่ต้องเลือกสร้างเว็บไซต์และระบบจองกับ พักอิน
- 9:16 1080x1920 ≤1:30 · 2D Animated Explainer จริงจัง มีสาระ ทันสมัย (flat vector สีสด ไม่มีเส้นขอบ ตามกฎสตูดิโอ)
- ตัวละคร: เจ้าของโรงแรม, พนักงานต้อนรับ, นักท่องเที่ยว — สุภาพ มืออาชีพ
- โทนสี: น้ำเงินกรมท่า, ฟ้าดิจิทัล, ขาว, ส้มทองอ่อนเน้นจุดสำคัญ · ไม่เล่นมุกตลก
- ฉาก1 (บริบท): สมาร์ทโฟนจองที่พัก กราฟเปรียบเทียบช่องทางการจองและตัวตนแบรนด์ กล้องซูมเข้า/แพน
- ฉาก2 (ปัญหา): ลูกค้ากดออกเพราะเว็บช้า สลับภาพหลังบ้านวุ่นวาย จดมือ ไฟล์ซ้ำซ้อน ห้องซ้ำ/ตกหล่น
- ฉาก3 (พักอิน): เว็บไซต์โรงแรมโดยพักอิน เชื่อมหลังบ้านเรียลไทม์ ใช้งานง่าย
- ฉาก4 (ผลลัพธ์): ธุรกิจราบรื่น แขกพึงพอใจ โลโก้พักอินเด่น (การ์ดขาวมุมมน) ซูมออกช้า
- เปลี่ยนฉาก: slide / fade / zoom ลื่นไหล · SFX: คลิก UI เบา แจ้งเตือนนุ่ม (tonal)
## การตัดสินใจของผู้ใช้
- เร่ง VO 1.1x = ใช่ (vo_raw.mp3 = ต้นฉบับ; vo.mp3 = เร่ง 1.1x ด้วย atempo ไม่เปลี่ยนระดับเสียง)
- ดนตรี = สดใสน่ารัก (ตามกฎถาวร) ducking ตอนพูด
- ซับ = ทั้งสองแบบ: ซับล่างตามบทพูดจริง + ข้อความสรุปรายฉากเป็นหัวข้อในภาพ (ข้อความตามนี้เท่านั้น ห้ามเติม):
  1. นักท่องเที่ยวจองที่พักผ่านมือถือเป็นหลัก พึ่งตัวกลางอย่างเดียว อาจเสียกำไรและตัวตนของแบรนด์!
  2. เว็บช้า จองยาก ไม่รองรับมือถือ = เสียลูกค้าทันที หลังบ้านไม่เรียลไทม์ = เสี่ยงห้องซ้ำและตกหล่น!
  3. พัฒนาเว็บไซต์ ระบบจองตรง และระบบหลังบ้านกับ "พักอิน" หน้าบ้านสวยจองลื่น หลังบ้านครบวงจร ลดงานซ้ำซ้อน!
  4. ระบบแข็งแรง เว็บไซต์น่าเชื่อถือ มีเวลาดูแลแขกเต็มที่ ยกระดับระบบโรงแรมให้เติบโตมั่นคง วางใจ "พักอิน"
