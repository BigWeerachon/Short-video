# บรีฟ — นิสัยการจองโรงแรมของคนเกิด 7 วัน: สไตล์ไหน พักอิน ก็เอาอยู่
- 9:16 1080x1920 · 2D explainer คอมเมดี้สดใส · VO เร่ง 1.1x (vo_raw = ต้นฉบับ)
- ตัวละคร 7 วัน expressive โอเวอร์แอคติ้ง สีประจำวัน: จันทร์เหลือง อังคารชมพู พุธเขียว พฤหัสส้ม ศุกร์ฟ้า เสาร์ม่วง อาทิตย์แดง → ฉากพักอินโทนฟ้าดิจิทัล
- ฉาก1: จันทร์กางปฏิทินจองล่วงหน้าเป็นปี / อังคาร ตีสองขับรถ กดจองตอนติดไฟแดงหน้าซอย
- ฉาก2: พุธแว่นขยายอ่านรีวิวจนใยแมงมุมขึ้น ซูมกระเบื้อง / พฤหัสเครื่องคิดเลข / ศุกร์เซลฟี่มุมสวย
- ฉาก3: เสาร์นั่งชิลเบาะหลังรถเพื่อน ถามนอนไหน / อาทิตย์แว่นดำกดโอนมาดบอส
- ฉาก4: 7 ตัวรวมรอบหน้าเว็บพักอิน แจ้งเตือนจองสำเร็จเรียลไทม์ โลโก้บนการ์ดขาวมุมมนกึ่งกลาง
- เปลี่ยนฉาก: jump cut / whip pan ฉับไว แต่ห้ามตัดกลางประโยค (L21)
## ตามกฎสตูดิโอ (ปรับจากบรีฟ)
- ไม่มีการ์ดข้อความ/หัวข้อในภาพ (L22) — ข้อความสรุปที่ให้มาไม่ใส่ ใช้ซับล่างตามบทพูดเท่านั้น; ห้ามตัวเลขจำนวนคลิกในภาพ (L17) ไม่มีตัวอักษรบนจอ/ปฏิทิน/เครื่องคิดเลข
- ดนตรี: คอมเมดี้สดใส ใช้ ukulele เปลี่ยนตามตัวละคร
- SFX tonal เท่านั้น (L15): พลิกปฏิทิน/ชัตเตอร์ → ทำเป็นโทนดนตรีแทนเสียงกระดาษ/คลิก; แตรรถ = โน้ตบีบแตรแบบโทน; เครื่องคิดเลข = บี๊บโทน; แจ้งเตือนโอน = chime
- ตัดเสียงหายใจใน VO (mutes)
