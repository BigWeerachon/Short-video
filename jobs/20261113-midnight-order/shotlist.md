## ของใหม่ที่ต้องสร้างใน engine
- **ตัวละคร rider** (cast.js): สูงเท่า narrator, แจ็กเก็ตไรเดอร์เขียวสด, หมวกกันน็อกเต็มใบสีเดียวกัน ชิลด์ใสเปิดขึ้นเห็นหน้า, กล่องอาหารเหลี่ยมสีเขียวด้านหลัง/ในมือ; ใช้ expr ที่มีใน rig (happy/scared/shock ฯลฯ) + เพิ่ม expr `swirl` (ตาก้นหอย) และ `sweat`; mode `ride` (นั่งบนรถ แขนจับแฮนด์ด้วย IK L03)
- **ตัวละคร ghost** (cast.js): ผีสาวชุดขาวยาวคลุมเท้า ปลายชุดเป็นคลื่นลอย ไม่มีขา, ผมดำยาวปิดหน้า (โชว์แค่ตากลมจุดขาว), ผิวฟ้าซีดอ่อน, pose `smile` = แหวกผม ยิ้มโค้งกว้างถึงหู ฟันขาวเรียบเป็นแถบ ไม่มีเลือด/เส้นเลือด แก้มชมพู → ตลกมากกว่าน่ากลัว; anim: ลอยขึ้นลง sin, โบกมือช้า, คอเอียง; flat ไม่มีเส้นขอบ
- **prop motorcycle**: สกู๊ตเตอร์ส่งอาหาร มุมข้าง+มุมหลัง, ล้อหมุน, ไฟหน้า = ลำแสงสามเหลี่ยมเหลืองโปร่งออกจากหัวโคม (L05 ลำแสงออกจากตัวไฟ)
- **bg roadNight**: ฟ้าน้ำเงินเข้ม, ดาวจาง, pines เงาดำสองชั้น parallax, ถนนเส้นกลางประ, เสาไฟดับ (ไม่มีแสง), speedLines option
- **mirrorView**: กรอบกระจกมองหลังวงรีสีเทา ก้านยื่น, ด้านในวาดฉากถนน (clip) + slot ใส่ตัวละครข้างใน
- **hotelRoom**: ผนังฟ้าอ่อน, เตียงขาว+ผ้าห่มฟ้า (state: คลุมถึงตา), aircon ติดผนัง + เกล็ดหิมะ/เส้นลมการ์ตูนลอยออก, หน้าต่างที่ไล่ฟ้ามืด→เช้า
- **clock02**: นาฬิกาดิจิทัล/ปลุก แสดง 02:00 (prop ไม่ใช่การ์ด)
- **sky preset**: `neonStudio` (ม่วงเข้ม+แถบนีออนส้ม), `digitalSky` (ฟ้าใส + กริดจางๆ)
- **phone screens**: หน้าแอปไรเดอร์ (ไอคอนชานมไข่มุก + แผนที่หมุด), หน้าเว็บโรงแรม (logoCard พักอิน บนการ์ดขาว + การ์ดห้อง + ปุ่ม) ไม่มีตัวหนังสือที่ไม่ได้สั่ง, ติ๊กถูกเขียว
- **fx**: ตัวสั่น/ขาสั่น, ขนลุก, วิญญาณลอยออกหัว, กล้องสั่น (camera shake)
